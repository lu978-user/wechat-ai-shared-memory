# 故障排查

- **推送失败或上游 5xx：** 检查服务健康、网络/代理与上游响应；单次 5xx 不一定表示登录态失效。
- **systemd 单元丢失：** 检查环境变化，再核对备份单元、恢复脚本和文件权限。恢复脚本会执行高权限操作，不得从不可信或普通用户可写的位置运行。
- **会话失效：** 按上游工具提示由账号所有者重新扫码。二维码、Token 和登录态不得发到聊天或 issue。
- **收件箱计数失败：** 检查服务状态、配置路径、网络和工具版本；不要将含秘密的异常输出贴到公开 issue。
- **重复唤醒：** 检查消息认领（lease）、处理和确认（ack）流程，并评估节流窗口。Hook 依赖 Muse 运行时，需在目标平台验证。
