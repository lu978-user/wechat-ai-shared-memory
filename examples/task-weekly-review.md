# 任务规范示例：每周学习复盘

> **示例模板，非实际部署配置。** 本文件不是任何已部署任务的原文，也不是独立可执行程序。部署者应自行决定时间、数据来源优先级和推送目标；不得公开真实微信标识或文档 ID。

每周日北京时间 21:00，优先读取共享记忆台账当周记录，再结合已授权的备用台账。只统计本周新增记录，不把历史基线重复算成本周成果。共享文档不可用时说明原因。

只使用真实记录。若没有当周进度，不生成虚构复盘，只询问用户。复盘结构：完成情况、问题与薄弱点、效率观察、下周规划；下周核心任务最多 3 项。

推送命令示例：`wx-bot send --binding <BINDING> --to <YOUR_WXID> --text -`。
