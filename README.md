# WeChat AI Bridge & Shared Memory

面向个人 AI 助手的微信消息桥接与跨会话共享记忆实践。

> **项目状态：原型验证完成，开源整理中。** 当前公开仓库还没有完整的可运行源码。请不要把本仓库误认为已经可以一键部署的成品。

## 项目目标

把 AI 助手放进日常使用的微信聊天流程，并让不同会话或助手能够基于同一份经过授权的共享记忆协作。

- **微信消息桥接**：在微信中向 AI 助手发送消息，并接收回复。
- **共享记忆**：通过授权的 Google Docs 文档保存可跨会话读取的项目背景、目标和进度记录。
- **定时任务**：支持晨报、周复盘等主动推送场景；具体调度配置取决于部署环境。
- **安全优先**：凭据与个人记忆不进入公开仓库，敏感写入操作应经过确认。
